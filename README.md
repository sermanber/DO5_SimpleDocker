# Simple Docker

Введение в докер. Разработка простого докер-образа для собственного сервера.

## Introduction

В данном проекте изучены основы работы с Docker. Выполнена настройка готового веб-сервера Nginx в контейнере, 
написан собственный мини-сервер на C с использованием FastCGI, а также создан собственный докер-образ для него. 
Проверена безопасность образа с помощью Dockle, а развертывание нескольких контейнеров автоматизировано с 
помощью Docker Compose.

## Part 1. Готовый докер

- Официальный докер-образ с **nginx** скачан с помощью `docker pull`, наличие образа проверено командой `docker images`.
- Создан и запущен контейнер на основе образа (команда `docker run -d`), проверен его статус (`docker ps`).
- Получена информация о контейнере (`docker inspect`), определены размер контейнера, список замапленных портов и ip-адрес.
- Контейнер остановлен (`docker stop`) и проверено, что он остановился.
- Докер запущен с портами 80 и 443, замапленными на аналогичные порты локальной машины. Проверена доступность стартовой страницы **nginx** в браузере по адресу *localhost:80*.
- Выполнен перезапуск контейнера (`docker restart`) и проверена его работоспособность.

## Part 2. Операции с контейнером

- Прочитан конфигурационный файл *nginx.conf* внутри докер-контейнера через команду `exec`.
- Создан локальный файл *nginx.conf*, в нем настроена отдача страницы статуса сервера **nginx** по пути `/status`.
- Созданный файл скопирован внутрь докер-контейнера через `docker cp`, **nginx** перезапущен внутри контейнера. Проверена доступность страницы *localhost:80/status*.
- Контейнер экспортирован в файл *container.tar* (команда `export`).
- Контейнер остановлен и удален, образ удален через `docker rmi`.
- Создан образ из файла *container.tar* через команду `import`. На его основе создан и запущен контейнер, проверена отдача страницы по адресу *localhost:80/status*.

## Part 3. Мини веб-сервер

- Написан мини-сервер на **C** и **FastCgi**, возвращающий страничку с надписью `Hello, World!`.
- Мини-сервер запущен через *spawn-fcgi* на порту 8080.
- Написан свой *nginx.conf*, который проксирует все запросы с 81 порта на *127.0.0.1:8080*.
- Локально запущен **nginx** с написанной конфигурацией, проверена отдача странички в браузере по *localhost:81*.
- Файл *nginx.conf* размещен по пути *./nginx/nginx.conf* для дальнейшего использования.

## Part 4. Свой докер

- Написан собственный докер-образ (Dockerfile), который:
  - собирает исходники мини-сервера на FastCgi;
  - запускает его на 8080 порту;
  - копирует внутрь образа написанный *./nginx/nginx.conf*;
  - запускает **nginx**.
- Докер-образ собран через `docker build` с указанием имени и тега, корректность сборки проверена через `docker images`.
- Запущен собранный докер-образ с маппингом 81 порта на 80 локальной машины и маппингом папки *./nginx* внутрь контейнера.
- Проверена доступность странички мини-сервера по *localhost:80*.
- В *./nginx/nginx.conf* добавлено проксирование странички `/status` для отдачи статуса сервера **nginx**.
- Образ пересобран. Проверена отдача странички статуса по адресу *localhost:80/status*.

## Part 5. Dockle

- Образ из предыдущего задания просканирован через утилиту `dockle`.
- Докерфайл исправлен таким образом, чтобы при проверке через **dockle** не было ошибок и предупреждений (устранены замечания по безопасности).

## Part 6. Базовый Docker Compose

- Написан файл *docker-compose.yml*, с помощью которого:
  - поднимается докер-контейнер из Части 5 (работает в локальной сети без маппинга портов на локальную машину);
  - поднимается докер-контейнер с **nginx**, который проксирует все запросы с 8080 порта на 81 порт первого контейнера.
- 8080 порт второго контейнера замаплен на 80 порт локальной машины.
- Все запущенные ранее контейнеры остановлены.
- Проект собран и запущен с помощью команд `docker compose build` и `docker compose up`.
- Проверена отдача написанной странички в браузере по адресу *localhost:80*.
